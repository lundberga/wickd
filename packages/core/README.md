# wickd-core

Shared types, trace schema, and cost-per-token tables for [Wickd](https://wickd.dev).

This is an internal package — install [`wickd`](https://www.npmjs.com/package/wickd) instead.

```bash
npm install wickd
```

## What's here

- Trace and budget type definitions
- Model pricing tables (OpenAI, Anthropic, Google)
- `calculateCost()` and `getPrice()` helpers
